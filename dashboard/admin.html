What this dashboard can and cannot show you. Every number here is built from event metadata: a category, a hostname, a department, an action, and an anonymous ID. There is no view, query, or export that reveals what an employee wrote or which file they attached — the flagged_events table has no column capable of holding it. You also cannot map an anonymous ID back to a person: that mapping lives in a table your admin account is denied access to by row-level security.
